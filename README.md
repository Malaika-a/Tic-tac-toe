## 🧩 Overview

<table>
<tr>
<td width="60%" valign="top">

**Tic Tac Toe** is a console-based two-player game built in **C++**, where a human competes against an AI opponent powered by the **Minimax algorithm**. Instead of guessing, the AI simulates every possible outcome before choosing its move.

Since Tic Tac Toe is a mathematically solved game, perfect play always ends in a draw — this AI **never loses**.

## ✨ Features

![Gameplay](https://img.shields.io/badge/🎮-Gameplay-E67E22?style=for-the-badge)

- Classic 3x3 grid Tic Tac Toe
- Choose to play as **X** or **O**
- Turn-based logic with input validation

![AI](https://img.shields.io/badge/🤖-AI_Engine-8E44AD?style=for-the-badge)

- Powered by the **Minimax algorithm**
- Evaluates every possible future move
- Always plays the mathematically optimal move

![Detection](https://img.shields.io/badge/🏆-Detection-2ECC71?style=for-the-badge)

- Automatic **Win** detection
- Automatic **Loss** detection
- Automatic **Draw** detection

![Interface](https://img.shields.io/badge/🖥️-Interface-3498DB?style=for-the-badge)

- Clean, distraction-free console UI
- Clear row/column prompts
- Board reprinted after every move
